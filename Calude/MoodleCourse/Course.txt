    03 - SY302 Datenbanken / Bases de données
    SY302 Datenbanken 

    Datenbanken spielen in unserer computerisierten Welt eine entscheidende Rolle und sind für viele Aspekte unseres täglichen Lebens und unserer Wirtschaft von zentraler Bedeutung.

    Datenbanken bieten eine strukturierte Methode zur Organisation und Verwaltung grosser Datenmengen.

    Sie ermöglichen die effiziente Speicherung, Aktualisierung und Abfrage von Informationen und gewährleisten so einen geordneten Zugriff auf relevante Informationen.

    Diese Fähigkeiten und Kenntnisse werden im Rahmen dieses Kurses vermittelt.

14 .:. Webprojekt: Dynamische Webanwendung mit REST API

	
	
Projektauftrag 
	
 
	

Ausgangslage

Sie erhalten eine statische HTML-Webseite als Vorlage. Ihre Aufgabe ist es, diese Seite in eine dynamische, datenbankgestützte Webanwendung umzuwandeln.

Alternativ kann auch ein eigenes Webprojekt eingebracht werden, es muss aber die Projektziele erfüllen.

 

 
  	
 
	
Projektziele 

1. Datenbankdesign (15 Punkte)

    Erstellen Sie ein ER-Diagramm mit 4-5 Entitäten
    Die Tabellen müssen in Beziehung zueinander stehen (mind. 2x 1:N, 1x N:M)
    Normalisierung bis 3. Normalform
    Dokumentation der Tabellen mit Datentypen und Constraints

2. Datenbank-Implementation (10 Punkte)

    Umsetzung in MariaDB/MySQL
    SQL-Script für Tabellenerstellung (CREATE TABLE)
    Testdaten einfügen (mind. 5 Datensätze pro Tabelle)
    Abgabe als .sql Dump-Datei

3. REST API Backend (30 Punkte)

Entwickeln Sie ein Node.js Backend mit folgenden Anforderungen:
Technische Requirements:

    Framework: Express.js
    Datenbankanbindung: mysql2 oder Sequelize/Prisma
    Umgebungsvariablen: .env für DB-Credentials
    Fehlerbehandlung mit passenden HTTP-Status-Codes

API-Endpoints (mind.):

Mindestens eine Ressource muss alle CRUD-Operationen unterstützen:

GET    /api/[resource]          - Alle Datensätze abrufen
GET    /api/[resource]/:id      - Einen Datensatz abrufen
POST   /api/[resource]          - Neuen Datensatz erstellen
PUT    /api/[resource]/:id      - Datensatz aktualisieren
DELETE /api/[resource]/:id      - Datensatz löschen

Weitere Endpoints:

    Mind. 2 Endpoints mit JOIN-Operationen (verknüpfte Tabellen)
