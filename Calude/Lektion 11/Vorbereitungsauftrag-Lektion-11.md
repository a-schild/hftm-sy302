# Vorbereitungsauftrag Lektion 11: MVC Pattern & Frameworks

## Ziel

Vorbereitung auf Lektion 11, in der wir Express-Projekte nach dem MVC-Pattern strukturieren und ORMs (Object-Relational Mapping) einsetzen werden.

## Aufgaben

### 1. MVC Pattern Recherche (ca. 30 Minuten)

Recherchiere das **Model-View-Controller (MVC) Pattern** und beantworte folgende Fragen schriftlich:

**a) Grundverständnis:**
- Was ist das MVC-Pattern und wozu dient es?
- Welche drei Hauptkomponenten gibt es und welche Verantwortung hat jede Komponente?
- Zeichne ein einfaches Diagramm, das zeigt, wie die drei Komponenten miteinander interagieren.

**b) Vorteile & Nachteile:**
- Nenne mindestens 3 Vorteile des MVC-Patterns
- Gibt es auch Nachteile oder Situationen, wo MVC nicht ideal ist?

**c) Praktische Anwendung:**
- Wie würdest du ein einfaches REST API für eine Bibliothek (Bücher, Autoren) nach MVC strukturieren?
- Welche Dateien/Klassen würdest du erstellen?
- Welcher Code gehört in welche Schicht?

**d) Vergleich:**
- Was ist der Unterschied zwischen "Model" im MVC und "Model" im Datenbankdesign (ERD)?

### 2. Bestehendes Projekt analysieren (ca. 20 Minuten)

Schaue dir dein bisheriges REST API Projekt an:

- Wo ist aktuell der Code für DB-Zugriff?
- Wo ist die Business-Logik (Validierung, Berechnungen)?
- Wo werden HTTP-Requests verarbeitet?
- Ist der Code bereits nach MVC strukturiert? Wenn nein, wie würdest du es umstrukturieren?

Erstelle eine kurze Übersicht (Stichpunkte genügen):
```
Aktuelle Struktur:
- Datei X: enthält [DB-Zugriff / Business-Logik / Request-Handling]
- Datei Y: ...

Verbesserungsvorschläge für MVC:
- Model Layer: [was gehört hier rein?]
- Controller Layer: [was gehört hier rein?]
- Route Layer: [was gehört hier rein?]
```

### 3. Framework vs. Library (ca. 10 Minuten)

Recherchiere kurz den Unterschied zwischen einem **Framework** und einer **Library**.

Beantworte:
- Was ist der Hauptunterschied?
- Ist Express.js ein Framework oder eine Library? Warum?
- Kennst du andere Beispiele für Node.js Frameworks?

### 4. ORM Vorabkenntnis (optional, ca. 15 Minuten)

Falls du Zeit hast, informiere dich kurz über **ORM (Object-Relational Mapping)**:

- Was ist ein ORM?
- Welche bekannten ORMs gibt es für Node.js?
- Was sind Vor- und Nachteile von ORMs gegenüber rohen SQL-Queries?
